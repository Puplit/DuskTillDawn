No purge siren ships with pup-events.

Add your own siren file here (one you have the rights to; .ogg or .mp3 decode most
reliably), then set its path in config/events.lua under purge.siren.file,
e.g. file = 'sounds/siren.ogg'. With no file set, the purge starts in silence.
/purgesirentest plays it on demand.
